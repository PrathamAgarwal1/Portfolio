## What it is

A real-time collaboration platform for developers. It combines a browser IDE, video and audio calls, collaborative editing and competitive matchmaking in one workspace, for pair programming, interviews or coding battles.

## Features

- **Real-time collaboration:** edit code and documents together, synchronised with Yjs over WebSockets.
- **Video calls** inside the workspace, powered by Mediasoup (WebRTC).
- **Live code execution** in the browser IDE.
- **Matchmaking:** opponents are scored on ELO proximity and the cosine similarity of their skill vectors, with bonuses for slightly stronger opponents and fair queue times.
- **Projects and rooms** you can invite friends into.

Built with React, Node.js, Express, MongoDB, Socket.io, Yjs and Mediasoup.
